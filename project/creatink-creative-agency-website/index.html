About the Project

Architected a resilient static web hosting pipeline on AWS using S3 for object storage and CloudFront CDN for global edge caching with sub-100ms latency.

Timeline:

2026

Domain:

Cloud & DevOps

Services:

AWS S3, CloudFront, Route 53, CI/CD

Project Details

Configured automated DNS routing via Route 53 with SSL/TLS encryption via AWS Certificate Manager (ACM) and GitHub Actions CI/CD.

Enforced private S3 bucket policies with CloudFront Origin Access Control, ensuring all assets are delivered through edge points with automated cache invalidation.

“Deploying global edge distributions on AWS CloudFront paired with automated GitHub Actions achieved reliable sub-100ms response times worldwide.”

Things I Did

Configured private S3 bucket storage with CloudFront CDN distribution and custom caching policies.

Automated DNS routing, ACM SSL encryption, and continuous deployment via GitHub Actions.
